# Lista de verificación

- [ ] Gradle sincroniza y compila sin errores.
- [ ] Se puede registrar un cliente.
- [ ] Se rechazan alias duplicados y contraseñas inválidas.
- [ ] Inicio de sesión con credenciales correctas.
- [ ] No se puede entrar con contraseña incorrecta.
- [ ] Catálogo, filtros, detalle y favoritos funcionan.
- [ ] Favoritos separados por cliente y persistentes tras reiniciar.
- [ ] Cotizaciones guardadas en Room, fecha futura validada.
- [ ] Solicitudes separadas por cliente.
- [ ] Cámara y galería muestran vista previa.
- [ ] QR válido abre producto; QR inválido muestra error.
- [ ] Lectura QR se guarda en SQLite.
- [ ] Mapa muestra marcador de demostración con API key.
- [ ] Cliente no tiene acceso administrativo.
- [ ] Documentar qué requisitos están pendientes de backend/Firebase.
- [ ] Adjuntar evidencias de GitHub y Trello.
